SAKSHI ORBIT — IMMERSIVE PORTFOLIO

Run:
1. Extract this folder.
2. Open index.html in Chrome / Edge / Safari.
3. For best voice results, use Chrome/Edge and click "Play intro". The browser chooses an available English voice, preferring female-sounding system voices when available.

No build step. No npm required.

Important:
- The portfolio uses Sakshi's supplied transparent full-body image at assets/sakshi.png.
- The site is intentionally redesigned from scratch: editorial/cinematic, restrained blue/teal, no childish gradient cards.
- The "Hear Sakshi" feature is browser text-to-speech. Exact lip-sync from a still image is not possible with HTML/CSS/JS alone; a real lip-synced presenter would require a generated video/avatar asset or external lip-sync service.
- Project links are the links supplied in the portfolio materials.
